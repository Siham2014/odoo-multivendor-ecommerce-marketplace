 📋 WORKFLOW STATE MACHINE
────────────────────────────────────────────────────────────────────────────────

Initial State: draft

State Transitions:
  draft ──submit──> submitted
  submitted ──assign──> assigned
  assigned ──start──> in_progress
  in_progress ──approve──> approved (MANAGER ONLY)
  in_progress ──reject──> rejected (MANAGER ONLY)
  approved ──refund──> refunded (MANAGER ONLY)
  rejected ──close──> closed
  refunded ──close──> closed

Valid Paths:
  1. draft → submitted → assigned → in_progress → approved → refunded → closed
  2. draft → submitted → assigned → in_progress → rejected → closed
  3. draft → submitted → assigned → in_progress → approved (no refund, no close)

Button Requirements:
  submit ...... No prerequisites
  assign ...... Requires responsible_id
  start ....... State must be 'assigned'
  approve .... State must be 'in_progress' + Manager + resolution_notes
  reject ..... State must be 'in_progress' + Manager + resolution_notes
  refund ..... State must be 'approved' + Manager + resolution_notes
  close ...... State must be 'rejected' or 'refunded'
